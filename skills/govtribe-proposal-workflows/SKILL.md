# GovTribe Proposal Workflows

Before your first GovTribe search, read [Choose a search mode and write queries](https://govtribe.com/docs/govtribe-for-agents/guides/choose-a-search-mode-and-write-queries), unless already in context. Alternatively, retrieve it with `Documentation` using `collections=["govtribe-for-agents"]` and `article_names=["Choose a search mode and write queries"]`.

## Proposal workflows

Choose references that match the request. Reuse the active opportunity, source files, requirement IDs, company evidence and selected draft. For amendments and follow-ups, update that work rather than restarting it.

- **What must we submit, and what changed?** [Solicitation Requirements and Amendments](references/solicitation-intelligence-and-compliance-extraction.md): identify instructions, evaluation factors, deadlines, forms and changes.
- **Build or update a compliance matrix, spreadsheet checklist or proposal tracker:** [Build or Update a Compliance Matrix](references/build-proposal-control-workbook.md).
- **Organize the technical response for our writers:** use **Annotated Proposal Outline** (`annotated-proposal-outline`) in `govtribe-file-templates` reference `references/annotated-proposal-outline.md` from its installed root.

## Response templates

Use the following guides from the installed File Templates root; retain a selected draft or required buyer form.

- **Answer an RFI or sources-sought notice:** `govtribe-file-templates` reference `references/rfi-sources-sought-response.md`.
- **Prepare an RFQ quotation:** `govtribe-file-templates` reference `references/rfq-quotation-response.md`.
- **Draft or revise a proposal response:** `govtribe-file-templates` reference `references/proposal-response.md`.
- **Complete a buyer's questionnaire, survey or form:** `govtribe-file-templates` reference `references/template-adaptation-and-revisions.md`.

## Supporting references

- **Find supporting company files:** [Search_User_Files](https://govtribe.com/docs/govtribe-for-agents/tools/search-user-files-mcp-tool); use [Vector-store content retrieval](https://govtribe.com/docs/govtribe-for-agents/guides/vector-store-content-retrieval) for passages and native file tools for originals or unsupported formats.

Use `govtribe-govcon-writing` for narrative and `govtribe-pricing-data` for price or staffing research. `govtribe-capture-workflows` owns pursuit decisions and past-performance selection; preparing a requested response does not require a prior bid/no-bid review.
