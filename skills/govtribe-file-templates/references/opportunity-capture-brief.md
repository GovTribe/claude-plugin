# Opportunity Brief

Use after selecting `opportunity-capture-brief`. If `template-library.md` is not beside this guide, no template is installed: create the sections under **Without a template** natively and ignore instructions to inspect or copy a template.

1. **Read the template before drafting.** Inspect every section and table prompt in the selected Word file; the detailed completion instructions are inside it. Use the NIST example for illustration only. Confirm the audience; external summaries should omit internal qualification and research-process commentary.
2. **Establish the current opportunity.** Reuse the notice, source files and requirement map. Confirm buyer, scope, status, amendments, response deadline/time zone and submission instructions as of the brief. For missing source research or amendment reconciliation, use **Solicitation Intelligence and Compliance Extraction** (`govtribe-proposal-workflows` → `references/solicitation-intelligence-and-compliance-extraction.md`, from that skill's installed root).
3. **Complete the brief.** Follow the template's prompts for the buyer's need, opportunity facts, requirements, risks, actions and sources. Preserve requirement conditions and alternatives, identify the source sections covered, and separate confirmed facts, capture implications and open questions. Make actions specific to the findings, with a date or trigger. For a requested pursuit recommendation, reuse **Bid / No-Bid Review** (`govtribe-capture-workflows` → `references/conduct-bid-no-bid-review.md`, from that skill's installed root).
4. **Check the saved document.** Reconcile dates and response controls throughout; retain source versions, locators and links. Use [Template adaptation and revision checks](template-adaptation-and-revisions.md) for native file creation, revision, page inspection and delivery.

## Without a template

Create an editable document titled with the opportunity name and "Opportunity Brief", showing the buyer or office and the as-of date, with these sections:

- **What the buyer needs:** what is being acquired, the buyer's operating problem and the intended outcome, with citations. Add verified scale or scope only when it helps the reader.
- **Opportunity at a glance:** a table of item, details and citation covering opportunity and identifier, notice type, status, response window and time zone, set-aside, NAICS, size standard, contract type, period, budget, evaluation, notice changes and linked contracts. State no notice changes only after review, and distinguish zero linked results from unavailable research.
- **Requirements:** the source sections covered and any exclusions, then one row per requirement with its conditions, alternatives and citation.
- **Pursuit risks:** access or eligibility, technical or delivery, schedule or competition, and commercial exposure, each with the specific exposure, consequence and source locator.
- **Capture actions:** each action with a date or trigger, including confirming source changes, obtaining missing information and checking for the next notice.
- **Sources:** any material source changes needing confirmation, then a numbered register with title, version or date, useful locators and links. Keep supplied company context separate from source facts.
